# Schüler helfen Schüler

**Status:** In Entwicklung

Eine Plattform zur Vermittlung von Schülern, die Unterstützung benötigen, mit Schülern, die anderen beim Lernen helfen möchten.

### Tech Stack

* Python
* Flask
* Flask-SQLAlchemy
* HTML / CSS / JavaScript

### Geplant

* Benutzerverwaltung
* Rollen- und Berechtigungssystem für Schüler, Lehrkräfte und Administratoren
* Vermittlung von Schülern und Helfern
* Datenbankverwaltung mit SQLAlchemy

### Ziel
Das Projekt soll eine vollständige Webanwendung mit strukturierter Backend-Architektur, Datenbankanbindung und verschiedenen Benutzerrollen werden.
